# ECC Engineering Skills

**Source:** `~/.gemini/config/skills/` (Global Native Execution Engine)

## Overview

ECC provides 200+ engineering skills organized by domain. Key categories relevant to DRISHTI:

### Backend & API
- `backend-patterns` - FastAPI, REST, GraphQL patterns
- `fastapi-patterns` - FastAPI specific patterns
- `api-design` - API contract design
- `api-connector-builder` - External API integration

### Database & Migrations
- `database-migrations` - Migration strategies, versioning
- `postgres-patterns` - PostgreSQL specific patterns
- `prisma-patterns` - ORM patterns
- `redis-patterns` - Caching patterns

### Frontend & UI
- `frontend-patterns` - React, Vite, TypeScript patterns
- `react-patterns` - Component patterns, hooks, state management
- `vite-patterns` - Build optimization
- `frontend-a11y` - Accessibility standards

### Testing & Quality
- `e2e-testing` - End-to-end test patterns
- `python-testing` - pytest patterns
- `benchmark` - Performance benchmarking

### Security & Architecture
- `security-review` - Code security review
- `architecture-decision-records` - ADR management
- `docker-patterns` - Container patterns
- `cost-aware-llm-pipeline` - LLM cost optimization
- `orch-add-feature` - Feature development workflow
- `orch-fix-defect` - Bug fix workflow
